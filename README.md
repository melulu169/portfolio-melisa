# Portfolio Personal - PFO1

## Descripción

Este proyecto corresponde a la primera Práctica Formativa Obligatoria (PFO1) de la carrera de Desarrollo de Software.

El objetivo fue crear una landing page personal utilizando HTML y CSS, aplicando buenas prácticas de estructura, diseño responsive y diferentes recursos visuales.

## Tecnologías utilizadas

- HTML5
- CSS3
- Google Fonts
- Flexbox
- Git y GitHub

## Secciones

- Inicio
- Sobre mí
- Habilidades
- Proyectos
- Contacto

## Decisiones de diseño

Para el diseño elegí una estética simple, moderna y minimalista, utilizando una combinación de tonos claros y oscuros y una tipografía moderna.

También incorporé tarjetas para los proyectos, efectos de transición y un diseño responsive para adaptar la página a distintos tamaños de pantalla.

## Uso de Inteligencia Artificial

Durante el desarrollo de este proyecto utilicé ChatGPT como herramienta de asistencia.

La utilicé principalmente para recibir orientación sobre la estructura HTML, estilos CSS, organización del proyecto y resolución de algunas dudas durante el desarrollo.

Revisé y adapté las propuestas recibidas, tomando las decisiones finales sobre el contenido, diseño y organización del proyecto.
